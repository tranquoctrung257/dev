# Các lệnh cơ bản trong shell
- pwd: hiện thị đường dẫn thư mục hiện tại (forder) mà bạn đang ở đó.
- cd: dùng để di chuyển trong các thư mục
- ls: dùng để xem nội dung thư mục. 
- cat: dùng để xem nội dung của file
- cp: dùng để sao chép file của thư mục hiện tại. 
- mv: dùng để di chuyển file, có thể đổi tên file.
- mkdir: dùng để tạo thư mục mới.
- rmdir: dùng để xóa thư mục trống.
- rm: dùng để xóa thư mục cùng nội dung bên trong.
- touch: cho phép bạn tạo file mới trống thông qua dòng lệnh.
- locate: dùng lệnh này để định vị vị trí của file.
- grep: cho phép tìm kiếm tất cả text thông qua tập tin nhất định.
- sudo: cho phép sử dụng các yêu cầu quyền quản trị hoặc quyền root.
- df: dùng để thông báo về dung lượng lưu trữ được sử dụng trên hệ thống, hiện thị theo tỉ lệ % và KB/s
- du: cho phép kiểu tra dung lượng của file hoặc thư mục.
- echo: dùng để chuyển dữ liệu vào một file.
- hostname: xác định tên của máy tính/ mạng máy tính.
- zip/unzip: nén và giải nén file.
- ping: kiểm tra kết nối mạng với sever nào đó.
- chown: cho phép thay đổi hoặc chuyển quyền sở hữu file sang tên người dùng được chỉ định.
- chmod: dùng để thay đổi quyền đọc, ghi và quyền thực thi file và thư mục.
- diff: so sánh nội dung 2 file từng dòng một, sau khi phân tích file này, sẽ xuất hiện các dòng không khớp nhau.
- tail: sử dụng để xem 10 dòng cuối cùng đoạn code nào đó.
- head; sử dụng để xem 10 dòng đầu tiên của đoạn code nào đó.
