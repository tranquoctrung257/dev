# Bài 2.1 Vai trò của HTML, CSS, Javascript 


## 1.HTML, CSS và JavaScript 

- HTML (HyperText Markup Language - Ngôn ngữ đánh dấu siêu văn bản), CSS (Cascading Style Sheets - Các tập tin định kiểu theo tầng) và JavaScript là 3 ngôn ngữ để phát triển web mà trình duyệt có thể hiểu. Chúng là các ngôn ngữ khác nhau nhưng có quan hệ mật thiết với nhau, mỗi ngôn ngữ được thiết kế cho những nhiệm vụ cụ thể. Việc hiểu rõ được cách chúng làm việc với nhau sẽ giúp bạn sớm trở thành một nhà phát triển web chuyên nghiệp.

- Những thứ cần nắm được 
    + HTML dùng để thêm ý nghĩa cho nội dung bằng cách đánh dấu nó 
    + CSS dùng để định dạng cho nội dung đã được đánh dấu bởi HTML 
    + JavaScript dùng để thêm chức năng giúp người dùng có thể tương tác nhiều hơn với trang web 


Tóm Lại
- HTML, CSS và JavaScript là 3 ngôn ngữ duy nhất mà trình duyệt có thể hiểu 
- HTML viết tắt của HyperText Markup Language, nghĩa là Ngôn ngữ đánh dấu siêu văn bản 
- CSS viết tắt của Cascading Style Sheets, nghĩa là Các tập tin định kiểu theo tầng 
- JavaScript là một ngôn ngữ lập trình, giúp thêm tính tương tác cho trang web 
- Ví HTML như phần khung của một ngôi nhà, thì CSS đóng vai trò trang trí cho ngôi nhà trở nên đẹp mắt, và JavaScript giúp ngôi nhà có nhiều tiện nghi hiện đại hơn. 


# Bài 2.2 Chi tiết về ngôn ngữ HTML

> Giới thiệu HTML :HTML (HyperText Markup Language, ý nghĩa: Ngôn ngữ đánh dấu siêu văn bản). Đúng vậy, HTML là ngôn ngữ đánh dấu, nó cung cấp cú pháp để đánh dấu nội dung và không chứa logic lập trình chẳng hạn như if...else. 

> HTML là ngôn ngữ đánh dấu, HTML không phải là một ngôn ngữ lập trình. 
 

- Ngôn ngữ đánh dấu 

Hiểu đơn giản, ngôn ngữ đánh dấu sẽ giúp bạn có thể đánh dấu nội dung theo cách mang lại ý nghĩa cho nội dung đó. Hãy tưởng tượng, bạn đang sử dụng một trình soạn thảo và muốn in nghiêng một đoạn văn bản. 
thẻ i được viết tắt của từ italic in nghiêng

- Siêu văn bản 

Siêu văn bản (hypertext) là loại văn bản chứa nhiều loại dữ liệu khác nhau như: văn bản, âm thanh, hình ảnh, video, … và các siêu liên kết đến các siêu văn bản khác. Trong khi đó, văn bản thông thường (không phải siêu văn bản) chỉ bao gồm nội dung văn bản và hình ảnh. Ví dụ: một tờ báo, các trang trong một cuốn sách, … không phải là siêu văn bản. 

Chính trang web này là một siêu văn bản. Tới được bài học này, chắc hẳn bạn đã trải qua nhiều loại nội dung khác nhau như: văn bản, hình ảnh, video, ... và các siêu liên kết. Như vậy, bạn có thể kết luận các trang web chính là siêu văn bản và HTML là ngôn ngữ để tạo ra chúng. 

- Cú pháp HTML cơ bản 
Cú pháp cơ bản của HTML bao gồm thẻ mở và thẻ đóng. 
Trong ví dụ trên, chúng ta có 1 thẻ h1. Thẻ h1 này được tạo nên từ thẻ mở \<h1> và thẻ đóng \</h1>. 

Trong HTML có rất nhiều thẻ. Tuy nhiên, trong bài này chúng ta chưa đề cập tới số lượng các thẻ và ý nghĩa của chúng. Mục tiêu của bài này là các bạn nắm được cú pháp cơ bản khi sử dụng các thẻ trong HTML. 

## Tóm tắt
- HTML là ngôn ngữ đánh dấu siêu văn bản (HyperText Markup Language) 
- HTML là ngôn ngữ đánh dấu, HTML không phải là một ngôn ngữ lập trình 
- Siêu văn bản (hypertext) là loại văn bản chứa nhiều loại dữ liệu khác nhau như: văn bản, âm thanh, hình ảnh, video, … và các siêu liên kết 
- Cú pháp cơ bản của HTML bao gồm thẻ mở và thẻ đóng. Ví dụ: Hôm nay là \<i>một ngày đẹp trời!\</i> thì \<i> là thẻ mở, \</i> là thẻ đóng. 

# Bài 2.4 Cấu trúc tiêu chuẩn của file HTML

> Mỗi file html sẽ có phần đuôi mở rộng là html. ví dụ index.html, product.html,.. 

Nội dung của mỗi file HTML cần tuân thử theo cấu trúc tiêu chuẩn sau:
```
<!DOCTYPE html>
<html>
    <head>
        <!--các thẻ meta ở đây-->        
    </head>
    <body>
        <!-- nội dung của trang web ở đây -->
    </body>
</html>
```

    + khai báo doctype có ý nghĩa là hướng dẫn cho trình duyệt web hiểu được phiên bản html mà web đang sử dụng. điều này đảm bảo rằng trang web được xử lý giống nhau trên nhiếu trình duyệt khác nhau 

    + phiên bản mới nhất là html5

### thẻ head
- thẻ <head> là nơi chứa các thẻ meta là thể cung cấp thêm thông tin hiện thị của trang web. ví dụ: tiêu đề trang web, các đường link tới file css, khản năng thu phóng của trang web,... 
- sử dụng thẻ head trong thẻ html: thẻ head trong thẻ html còn được gọi là thẻ con trực tiếp (thẻ con và nó không bị trung gian qua thẻ trang nào khác)

```
<!DOCTYPE html>
<html lang = "en">
    <head>
        <!-- các thẻ meta ở đây -->
    </head>
</html>
```


### thẻ body 

- thẻ <body> là nơi chứa toàn bộ nội dung hiện thị của web. mọi nội dung bạn từng nhìn thất trên các trang web đều nằm trong thẻ body 
- sử dụng thẻ body trong thẻ html 

```
<!DOCTYPE html>
<html lang = "en">
    <head>
        <!-- các thẻ meta ở đây  -->
    </head>
    <body>
        <!-- nội dung trang web ở đây -->
    </body>
</html>
```

> Lưu ý thử <head> và <body> luôn là thẻ con trực tiếp của thẻ <html> 


Tóm tắt

- DOCTYPE là dòng đầu tiên cần được khai báo trong mọi file HTML
- thẻ <html> chứa toàn bộ nội dung của trang web
- thẻ <head> chứa các thẻ meta, thẻ <body> chứa nội dung được hiện thị của trang web  
- thuộc tính lang sử dụng để chỉ định ngôn ngữ của trang web. các công cụ dịch ngôn ngữ và trình đọc màn hình sẽ sử dụng thuộc tính này
# Bài 2.6 Tìm hiểu về các thẻ meta 

> Thẻ meta: Trong bài học này chúng ta sẽ tìm hiểu về các thẻ meta được đề cập trong ví dụ dưới đây (phần thẻ \<head>) 

```
<!DOCTYPE html>
<html>
    <head>
        <meta charset="UTF-8" />
        <meta name="viewport" content="width=device-width,initial-scale=1.0"/>
        <title>tiêu đều của trang web</title>
    </head>
    <body>
        nội dung của trang web
    </body>
</html>
```
Qua bài học trước, chúng ta đã được hoặc về thành phần thẻ \<head> là nơi chứa các thẻ meta. thẻ meta được dùng để bổ sung thông tin cho trang web, các thông tin này thường được sử dụng bởi:trình duyêt,công cụ tìm kiếm như (google search) và các trình thu thập dữ liệu của mạng xã hội như facebook 

thẻ \<meta> được sử dụng để cung cấp thêm thông tin và dữ liệu cho trang web

thẻ meta là một trong số thẻ tự đóng (tiếng anh:self-closing tag), cách viết của nó đơn giả như ví dụ sau: 
\<meta/>

khi sử dung thử \<meta> chúng ta cần khai báo thêm thuộc tính để việc sử dụng thẻ này trở nên có ý nghĩa

Một số trường hợp phổ biến:
- chỉ định bảng mã kí tự cho trang web 
- cung cấp mô tả trang web cho công cụ tìm kiếm 
- chỉ định cách hiện thị trang web trên nhiều thiết bị (pc,mobile,tablet)

## Thẻ meta charset 

đây là thẻ cần được khai báo tại vị trí đầu viên trong thẻ \<head> 
```
<head>
    <meta charset="UTF-8" />
</head>
```

Thẻ meta với charset="UTF-8" có tác dụng hỗ trợ hiện thị các kí tự nàm ngoài khoảng A - Z ví dụ tiếng việt có dấu, tiếng trung, tiếng ả rập,.. 

Nếu bạn không khai báo meta charset tại vị trí đầu tiên trong thẻ <head> thì trong một số trường hợp trang web chữ kí tự phức tạp, trình duyệt sẽ cố gắng đoán bằng bằng bảng mã ký tự và có thể gây ra lỗi hiện thị không mong muốn. 

Điều kiện này khó xẩy ra. các trang web ngày nay hầu hết đều được triểu khai trên các máy chủ web có hỗ trợ UTF-8. Vì vậy, khai bào \<meta charset="UTF-8" /> là không cần thiết trong trường hợp này 

Tuy nhiên, không vì lí do trên mà chúng ta không sử dụng thẻ meta charset. Thực tế, vẫn có những máy chủ không mặc định hỗ trợ charset. để đảm bảo tính thống nhất về bảng mã kí tự trong trang web của bạn, mặc định chúng ta luôn sử dụng thẻ meta charset nhé. 

## Thẻ meta title
Tuy thẻ này không có từ meta nhưng vẫn nằm trong nhóm thẻ meta. đâu là thẻ chứa tiêu đề của trang web, tiêu đề này được sử dụng trong một số trường hợp.

- hiện thị tiêu đề trang web trên thanh tab của trình duyệt 
- hiên thị tiêu đề trong kết quả của công cụ tìm kiếm (ví dụ: google search ) 
```
<title>đây là tiêu đề được hiện thị ở thanh tab của trình duyệt</title>
```

## Thẻ meta viewport 
Để tối ưu hóa việc hiện thị giao diện web trên nhiều thiết bị có kích cỡ màn hình khác nhau như pc tablet bạn cần sử dụn thẻ meta viewport.

ví dụ sử dụng thử meta viewport: 
```
<meta name="viewport" content="width=device-width,initial-scale=1.0" />
```
Tóm lại là hỗ trợ tối ưu giao diện trên các thiết bị khác nhau và chủ yếu là các thiết bị màn hình nhỏ.


Nếu trang web của bạn không có thẻ meta viewport thì khi mở tên thiết bị di động nội dung sẽ bị thu nhỏ, bạn cần phóng to để dễ dàng đọc được. Các trang web được xây dựng vào khoảng những năm 2010 thường gặp vấn đề này. 
Sau đó trào lưu thiết kế web đáp ứng hay reponsive web design xuất hiện. Tới ngày nay, hầu hết mọi trang web đều được tối ưu hiện thị trên nhiều thiết bị bào gồm cả mobile đương nhiên, các trang web được tối ưu cho đa thiết bị đều sử dụng thẻ meta viewport.

# Bài 2.8 Các thẻ HTML thông dụng 



## Thẻ h1 h2
Trong html có 6 thẻ được dùng để làm tiêu đề h1-h6. trong đó chữ h được viết tắt từ heading(ý nghĩa: tiêu đề phần mở đầu). trong bài học này, mình sẽ giới thiệu trước cho các bạn 2 thẻ là <h1> và <h2> vì đây là 2 thẻ được sử dụng phổ biến nhất trong số các thẻ tiêu đề.

```
<!-- cách sử dụng: -->
<h1>Nội dung tiêu đề chính</h1>
<h2>nội dung tiêu đều phụ</h2>
```

Thẻ <h1> được sử dụng làm tiêu đề chính, ví dụ tiêu đề của 1 bài blog. các thẻ <h2> được sử dụng làm tiêu đề phụ, ví dụ dùng làm các tiêu đề thể hiện ý chính trong bài blog

Tiêu đề chính thường thấy trong: tiêu đề của bài blog, tên sản phẩm, tên sản phẩm trang TMĐT, tên một bài học,..

Tiêu đề phụ thường thấy trong các ý chính của một bài viết.

## Thẻ p
Thẻ <p> để thể hiện các đoạn văn, p là viết tắt của pararaph(ý nghĩa:đoạn văn bản). thẻ <p> được sử dụng để thể hiện các đoạn văn bản trong nội dung bài viết như: mô tả blog, các đoạn văn bản trong bài blog, các đoạn văn bản trong nội dung sản phẩn, nội dung các bình luận trên mạng xã hội.

```
<!-- cách sử dụng -->
<p>đoạn văn 1</p>
<p>đoạn văn 2</p>
```
```
<!-- ví dụ  -->
<p>bài viết này nhằm tổng hợp lại các dự án mà học viên F8 đã hoàn thành và chia sẻ trên nhóm học lập trình web F8</p>
```

## Thẻ b,i,u
Đây là 3 thẻ khá quen thuộc nếu các bạn đã sử dụng các trình soạn thảo văn bản. trong đó b được viết tắt của bold(ý nghĩa:in đậm), i viết tắt của italic (ý nghĩa:in nghiêng) u viết tắt của underline(ý nghĩa: gạch chân, tương tự như trên trình soạn thảo văn bản)

```
<!-- cách sử dụng -->
<b>đoạn văn được in đậm</b>
<i>đoạn văn được in nghiêng</i>
<u>đoạn văn được gạch chân</u>
```

```
ví dụ 
<b>hôm nay</b> là <i>một ngày</i> <b>đẹp trời</b>
```

## Thẻ a
Khi truy cập trang web bạn gần như luôn bắt gặp các thẻ a, thẻ này tạo ra một siêu liên kết tớt các trang web, các email,file,... trong đó a viết tắt của anchor(ý nghĩa điểm neo,neo một liên kết)

```
<!-- cách sử dụng  -->
<a href="liên kết">đoạn văn bản cần nhấn</a>
```

```
<!-- ví dụ  -->
bạn có thể nhấn <a href="https://fullstack.edu.vn">nhần vào đây</a> để tới trang web của F8
```

## thẻ img 
Đây là thẻ dùng để hiện thị hình ảnh trên trang web. trong đó img viết tắt là image(ý nghĩa là hình ảnh). trong một trang web, hình ảnh được sử dụng rất phổ biến: logo trang web, ảnh đại diện, ảnh bìa. hình ảnh các mặt trên trang web TMDT,...

```
<!-- cách sử dụng -->

<img src="kiên kết đến hình ảnh" />
<!-- ví dụ -->
<img src="link" />

```
## Thẻ ul,li.
Thẻ ul và li được sử dụng để tạo giao diện danh sách,2 thẻ này được sử dụng rất phổ biến trong nội dung các bài viết.

Trong đó ul, viết tắt của unordered list (ý nhĩa danh sách không có thứ tự) và li viết tắt của list item(y nghĩa:mục trong danh sách)
```
<!-- cách sử dụng -->
<ul>
    <li>nội dung 1</li>
    <li>nội dung 2</li>
    <li>nội đung 3</li>
</ul>
```

```
<!-- ví dụ -->
<ul>
    <li>ngôn ngữ Html</li>
    <li>ngôn ngữ css</li>
    <li>ngôn ngữ javascript</li>
</ul>
```

## Thẻ ol,li 
- Gần giống như cặp thử ul,li. đây cũng là 2 cặp thẻ tạo giao diện danh sách. điểm khác biệt duy nhất nằm ở ol,ol viết tắt của ordered list(ý nghĩa: danh sách có số thứ tự) sử dụng thẻ này trong trường hợp bạn muốn thẻ hiện rõ số thứ tự của các mục trong danh sách.

```
<!-- Cách sử dụng -->

<ol>
    <li>nội dung 1</li>
    <li>nội dung 2</li>
    <li>nội đung 3</li>
</ol>
```

```
<!-- ví dụ  -->
<ol>
    <li>ngôn ngữ Html</li>
    <li>ngôn ngữ css</li>
    <li>ngôn ngữ javascript</li>
</ol>
```

Tóm Tắt
- thẻ h1 sử dụng làm tiêu đề chính, thẻ h2 sử dụng làm tiêu đề phụ
- thẻ p sử dụng để chứa các đoạn văn bản 
- thẻ b,i,u để in đậm, in nghiêng và gạch chân 
- thẻ a tạo ra các liên kết có thể nhấn vào, sử dụng thuộc tính href để chứa liên kết 
- thẻ img để hiện thị hình ảnh, liên kết tới hình ảnh được khai bảo trong thuộc tính scr 
- thẻ ul,li để hiện thị danh sách không có số thứ tự
- thẻ ol,li để hiện thị danh sách có số thứ tự 


# Bài 2.10 Tìm hiểu về thuộc tính trong HTML

> Thuộc tính là gì: thuộc tính(tiếng anh:attribute) được sử dụng để bổ sung thêm thông tin và dữ liệu cho thẻ HTML. các thuộc tính có dạng key="value" và luôn được viết trong thẻ mở của các thẻ html (không bao giờ được viết trong thẻ đóng)

Thực tế, các bạn đã được làm quen với một số thuộc tính của các thẻ HTML rồi đó.

thuộc tính lang trong thẻ \<html>

```
<html lang="vi">
    ...
</html>
```
Ví dụ trên có thuộc tính là lang="vi", nó gồm 2 phần 

1.lang

2.vi

Trong đó, lang được gọi là khóa của thuộc tính, vi được gọi là giá trị của thuộc tính.

> Cùng quan sát một số ví dụ sử dụng thuộc tính thường gặp khác:  

```
<!-- thuộc tính charset trong thẻ <meta>  -->
<meta charset="UTF-8"/>
```

```
<!-- thuộc tính href trong thẻ <a> -->
<a href="https://fullstack.edu.vn"Tới trang web F8></a>
```

```
<!-- thuộc tính src trong thẻ <img> -->
<img src="http://i3.ytimg.com/vi/1EBe-11E3pM/maxresdefault.jpg" />
```

Nhiều thuộc tính 
- Bạn có thể sử dụng đồng thời nhiều thuộc tính trong một thẻ html, mỗi thuộc tính(mỗi cặp key="value") được cách nhau bởi khoảng trắng.

Thuộc tính name và content trong thẻ <meta>viewport

```
<meta name="viewport" content="width=device-width", initial-scale="1.0" />
```
<!-- <!-- trong ví dụ trên có hai thuộc tính là: -->
1.name = "viewport"
2.content="width=device-width", initial-scale="1.0"

Trong thuộc tính thứ nhất có:
1.key: name
2.value:viewport

Trong thuộc tính thứ 2 có:
1.key:content
2.value: content="width=device-width", initial-scale="1.0" 


Thuộc tính toàn cục 

- Các thuộc tính được đề cập trong phần này có thể sử dụng cho toàn bộ cấc thẻ HTML. vì vậy, chúng được gọi là thuộc tính toàn cục(tiếng anh: global Attributes).

Thuộc tính lang 

- Mặc định thuộc tính lang không được sử dụng cho trang web. khi sử sụng bạn sử dụng thuộc tính nà cho thẻ <html> thì mặc đinh các thẻ trong trang web sẽ kế lại thuộc tính lang này 

```
<!-- ví dụ -->

<html lang="vi">
    ...
    <body>
        <!-- các thẻ p này cũng sẽ có lang="vi" -->
        <p>hôm nay là một ngày đẹp trời</p>
        <p>hôm qua cũng là một ngày đẹp trời</p>
    </body>
</html>
```

Chính vì điều này, nên nếu trang web của bạn có nội dung tiếng việt thì cần thêm <html lang="vi"> là đủ 

Tuy nhiên, có một số tình huống trang web của bạn vẫn đề cập tới một ngôn ngôn ngữ khác ngôn ngữ chính của trang web. trường hợp này, bạn có thể sử dung thêm thuộc tính lang cho thẻ chứa nội dung là ngôn ngữ khác 

```
<!-- ví dụ: -->

<html lang="vi">
    ...
    <body>
        <!-- thẻ p này có lang="vi" -->
        <p>hôm nay là một ngày đẹp trời</p>
        <!-- thẻ p này có lang="en" -->
        <p lang="en">Yesterday was also a beautiful day</p>
    </body>
</html>
```

Thuộc tính hidden sẽ được ẩn khỏi giao diện web(bao gồm cả các thẻ con và nội dung của nó.)
```
<!-- ví dụ  -->
<p>Hôm nay là ngày đẹp trời!</p>
<p hidden>hôm qua cũng là một ngày đẹp trời</p>
```

Sau này bạn có thể dùng javascript để thêm/bớt thuộc tính hidden để làm cho một thẻ html được ẩn/hiện trên giao diện trang web 


Thuộc tính title .

Đây là thuộc tính bổ sung thông tin cho một thẻ html, nội dung của thuộc tính này sẽ hiện thị khi bạn đưa con trỏ chuột vào phàn nội dung của nó: 

```
<!-- ví dụ  -->
<h1 title="Hướng dẫn học HTML,CSS hiệu quả"> cách học HTML,CSS hiểu quả</h1>
<a href="https://fullstack.edu.vn" title="Tới trang web của F8">fullstack.edu.vn</a>
```

ngoài ra, còn một số thuộc tính toàn cục chưa được đề cập tới trong bài này. bạn có thể tham khảo thêm [Tại đây.](https://www.w3schools.com/tags/ref_standardattributes.asp)

tóm tắt 
- thuộc tính(tiếng anh: attribute) được sử dụng để bổ sung thêm thông tin và dữ liệu cho các thẻ HTML.
- các thuộc tính luôn luôn được thêm vào phần thẻ mở, không bao giờ được thêm vào phần thẻ đóng. 
- có thể sử dụng nhiều thộng tính trong một thẻ HTML: ví dụ: <meta name="viewport" content="width=device-width", initial-scale="1.0" />
- các thuộc tính toàn cục có thể sử dụng cho mọi thẻ HTML. ví dụ: lang,hidden,title 

# Bài 2.11 Chia sẻ các mẹo để viết HTML tốt hơn.


Viết phần thẻ mở và thẻ đóng trước 

Tuân thủ các viết này, bạn sẽ không bao giờ bị quyên thẻ đóng.

Hãy bắt đầu với thẻ mở và thẻ đóng 

```
<h1></h1>

<!-- sau đó mới thêm phần nội dung:  -->
<h1>Hôm nay là ngày đẹp trời!</h1>
```

```
<!-- đối với thẻ tự đóng tiếng anh(self-closing tag). hãy bắt đầu với: -->

<meta />

<!-- sau đó mới thêm thuộc tính -->

<meta charset="UTF-8" />
```


Trình bày code ngắn gọn

Một bài văn tốt cần đúng chính tả. người viết văn là người hành văn, người viết code là người hành code. vậy viết HTML như thế nào cho đúng "chính tả"?

Thẻ con thụt lề 1 dấu tab so với thẻ cha 

Để đảm bảo tính dễ đọc, tránh nhầm lẫn khi số lượng code HTML nhiều lên, các bạn luôn thụt lề cho thẻ con bằng 1 dấu Tab(4 dấu cách ) so cới thẻ cha nhé

```
<!-- ví dụ: -->
<body>
    <h1>Hôm nay là một ngày đẹp trời!</h1>
    <ul>
        <li>Đầu mục 1</li>
        <li>Đầu mục 2</li>
        <li>Đầu mục 3</li>
    </ul>
</body>

```
```
<!-- dưới đây là ví dụ cho việc trình bày không ngay hàng, thẳng lối  -->

<body>
<h1>Hôm nay là một ngày đẹp trời!</h1>
<ul>
<li>Đầu mục 1</li>
<li>Đầu mục 2</li>
<li>Đầu mục 3</li>
</ul>
</body>
```

Thực tế, việc không ngay hàng thẳng lỗi có rất nhiều hình thái khác nhau, tùy vào cách viết của mỗi người, nhưng đều gay ra vấn đề chung đó là rất khó đọc và xác đinh được các thẻ mở và thẻ đóng. có thể dẫn tói việc viết thừa/thiếu thẻ mở/ thẻ đóng, gây lõi giao diện trang web.

Không có để dư các khoảng trắng 

Trong HTML, việc viết dư thừa các khoảng trắng hay các dấu ngắt dòng không gây ra lỗi giao diện. tuy nhiên, chúng ta không có lý do gò để viết dư các khoảng trắng. luôn đảm bảo viết code tối giarnm đơn giản, không dư thừa các khoảng trắng, đáu ngắt dòng không càn thiết 

```
<!-- ví dụ khoảng trắc trong thẻ mở của thẻ <body> -->
<body   >
    Nội dung của trang web 
</body>
```

```
Dư một khoảng trắng trước/sau thuộc tính lang:
<html   lang="vi">
    ...
</html>
```

```
<!-- khoảng trắng gữa 2 thuộc tính  -->
<a href="https://f8.edu.vn/"   title ="F8" >"Truy cap F8" </a>
```

```
<!-- dư dấu ngắt dòng trước thẻ đóng của thẻ <h1> -->

<body>
    <h1>hôm nay là ngày đẹp trời!
</h1>
</body>
```

Ngắt dòng hợp lý 
- Để đảm bảo tính dễ đọc cho code của các bạn khi viết HTML, các bạ cần tìm những điểm ngắt dòng hợp lý.

```
<!-- ví dụ, sử dụng dấu ngắt dòng hợp lý: -->

    <li>Đầu mục 1</li>
    <li>Đầu mục 2</li>
    <li>Đầu mục 3</li>
</ul> 

```
```
<!-- còn đây là trường lợp chưa hợp lý, làm code trở nên khó đọc hơn  -->

<ul><li>Đầu mục 1</li><li>Đầu mục 2</li><li>Đầu mục 3</li></ul> 
```

Đặt các thẻ đúng vị trí
- Có một số trường hợp các thể html được thiết kế để luôn nằm trong một thẻ cha khác.
thẻ \<head>,\<body> luôn là thẻ con trực tiếp của thẻ \<html> 

```
<html>
    <head>
        <!-- các thẻ meta  -->
    </head>
    <body>
        <!-- nội dung trang web -->
    </body>
</html>
```

```
<!-- tình huống sai: -->
<html>
    <head>
        <!-- các thẻ meta  -->
        <body>
            <!-- nội dung trang web -->
        </body>
    </head>
    <h1>hôm nay là một ngày đẹp trời!</h1>
</html>
```
Có 2 điểm chưa đúng 
1. thẻ \<body> đang nằm trong thẻ \<head>
2. thẻ \<h1> đang là thẻ con trực tiếp của thẻ \<html>  

Thẻ \<li> luôn là thử con trược tiếp của thẻ \<ul>,\<ol>:Unordered list
```
<ul>
    <li>Item 1</li>
    <li>Item 2</li>
    <li>Item 3</li>
</ul>
```
```
<!-- Ordered list -->
<ol>
    <li>Item 1</li>
    <li>Item 2</li>
    <li>Item 3</li>
</ol>
```

```
<!-- tính huống chưa đúng -->
<ul>
    <li>Item 1</li>
    <li>Item 2</li>
    <li>Item 3</li>
    <p>Some paragraph</p>
</ul>
```

Điểu sai ở đây là thẻ <p> đang là thẻ con trực tiếp của thẻ <ul>

- Quên http,https cho thuộc tính href 
ví dụ, chuyển hướng tới trang web google.com.vn khi nhấn vào thẻ \<a> bạn sẽ làm như nào?
